# Snake AI

Змейка с автопилотом, который гарантированно проходит поле любого
размера (проверено 5×5 … 30×30) при любом числе яблок — без столкновений
и без бесконечного хождения по кругу.

## Запуск

```
pip install pygame
python main.py
```

При запуске открывается **графическое меню** (консольный ввод больше не
используется): ширина и высота поля (5–30), число яблок, скорость игры
(4–20 FPS), режим игры и кнопка «Начать игру». Размер поля можно задать
стрелками, кнопками «−/+»
или быстрыми пресетами 10×10 / 15×15 / 20×20 / 30×30. Меню управляется
мышью и клавиатурой: **↑/↓** — выбор строки, **←/→** — изменение значения,
**1/2/3** — режим, **Enter** — старт, **Esc** — выход. Строка
**«Скорость игры (FPS)»** задаёт частоту ходов; выбранное значение
сохраняется для следующего запуска и отображается в HUD. В режиме
соревнования появляется строка **«Цель соревнования»**: можно выбрать от
1 до 50 яблок или включить **«До конца»** — игра идёт до полного
заполнения поля.

Режимы игры:

* **SMART** — автопилот играет сам;
* **MANUAL** — вы управляете стрелками / WASD;
* **СОРЕВНОВАНИЕ** — открываются два окна: слева играет ИИ, справа — вы.

Управление в игре: **M** — SMART/MANUAL, **SPACE** — пауза, **P** —
показать/скрыть запланированный путь, **R** — перезапуск, **ESC** — назад
в меню, стрелки/WASD — ручное управление. Скорость задаётся `FPS` в
`config.py`. Чтобы при запуске не открывалось окно консоли, используйте
`pythonw main.py`.

## Соревнование

В режиме **СОРЕВНОВАНИЕ** одновременно открываются два независимых окна:
в левом играет автопилот, в правом — человек. У обоих одинаковое поле,
одинаковое число яблок и одинаковые стартовые позиции яблок (общий seed,
но у каждой партии свой генератор случайных чисел).

* Цель выбирается в меню: **1–50 яблок** или **«До конца»** — до полного
  заполнения поля.
* ИИ и человек ходят с одинаковой частотой; форы по скорости больше нет.
* ИИ использует быстрый безопасный сбор яблок (BFS + проверка хвоста и
  свободной площади), а при усложнении позиции возвращается к
  гарантированному кольцу.
* Если змейка разбилась — она проигрывает.
* Змейка ИИ фиолетовая, ваша — синяя.
* Перед стартом идёт отсчёт 3 секунды; направление можно выбрать заранее.
* В обоих окнах виден общий счёт и выбранная цель, а заголовки окон
  показывают текущий счёт.
* **SPACE** — пауза обоих окон, **P** — путь ИИ, **R** — реванш,
  **ESC** — выход в меню, закрытие любого окна завершает приложение.
* Окна автоматически располагаются рядом и целиком помещаются на экране
  даже для поля 30×30.

## Размер окна

Размер клетки больше не фиксирован: `layout.py` подбирает его под рабочую
область экрана (без панели задач), поэтому окно с полем вплоть до 30×30
целиком помещается на экране. Окно центрируется по рабочей области, а под
сеткой остаётся информационная панель с параметрами партии и подсказками.
Стартовое меню показывает рассчитанный размер окна ещё до начала игры;
в режиме соревнования — размер каждого из двух окон.

## Как работает автопилот (`ai.py`)

1. **Кольцо.** Строится замкнутый маршрут через все клетки, каждой клетке
   присваивается номер на кольце. Если площадь поля чётная — это обычный
   гамильтонов цикл. Если обе стороны нечётные, такого цикла не существует
   (шахматная раскраска: клеток одного цвета на одну больше), поэтому угол
   и диагональная к нему клетка делят один номер: змейка проходит это место
   через любую из двух клеток.

2. **Инвариант.** Тело от хвоста к голове всегда идёт строго вперёд по
   кольцу. Пока это так, у головы всегда есть безопасный ход, поэтому
   столкновение невозможно ни сейчас, ни в будущем. Это доказуемое
   свойство, а не эвристика.

3. **Срезки.** Голова может прыгать вперёд на любую свободную клетку между
   собой и хвостом. Цель — ближайшее по кольцу яблоко (так ни одно яблоко
   не остаётся «за спиной»), путь — кратчайший среди безопасных (BFS).

4. **Яблоки за хвостом.** При 1–3 яблоках голова подтягивается к хвосту,
   при большем числе — идёт по кольцу (выбрано по замерам).

5. **Восстановление после ручного режима.** Если тело лежит «как попало»,
   ИИ ищет точный план ходов, после которого тело выстроится по кольцу,
   и дальше снова работает гарантированный режим.

6. **Быстрый безопасный режим.** ИИ не идёт сразу по кольцу: на каждом
   ходу он строит BFS-путь до ближайшего яблока, проигрывает путь по шагам
   (с учётом роста), проверяет достижимость хвоста и запас свободных
   клеток. Выбирается самый короткий безопасный путь; при равенстве —
   яблоко, рядом с которым есть другие. Быстрый режим работает, пока
   **коэффициент опасности** ниже 0,68. Он учитывает долю заполнения поля,
   тесноту малого поля и запас свободных клеток относительно длины тела.
   Фиксированного «первых N яблок» нет: на 5×5 FAST заканчивается примерно
   после 1 яблока, на 6×6 — после 2, на 7×7 — после 6, на 20×20 — после
   ~105. Как только порог достигнут или безопасного пути нет, ИИ
   возвращается к кольцу. Это позволяет собирать яблоки не медленнее
   человека и при этом не терять гарантию в длинной партии.

## Оформление

Поле, яблоко и голова змейки — PNG-ассеты в папке `assets`; они
масштабируются через `smoothscale`, поэтому не зависят от размера клетки.
Тело больше не собирается из квадратных тайлов: оно рисуется плавной
сужающейся лентой по сглаженной траектории (Chaikin), поэтому повороты
не выглядят как уголки шланга. Сегменты не интерполируются по
отдельности: игра запоминает след головы, а точки тела берутся через
равные расстояния вдоль этого следа. Голова — вытянутая капсула без
прямых углов; при поворотах она вращается с временным сглаживанием, а
сам спрайт поворачивается в увеличенном масштабе и уменьшается уже
после поворота. У головы большие глаза, которые периодически моргают,
две ноздри и спрятанный язык: раз в несколько секунд он высовывается
и снова прячется. Логика игры идёт с выбранной частотой (`FPS = 8` по
умолчанию), а кадры рисуются с `RENDER_FPS = 60`, поэтому на поворотах
длинная змейка не дёргается даже на 4 FPS.

В обычной игре змейка синяя, как в Google Snake; в соревновании ИИ
фиолетовый, игрок синий. Фон и HUD — тёмно-зелёные, с карточкой счёта и
полосой заполнения поля. Для паузы, победы и столкновения показывается
отдельный оверлей.

Ассеты можно перегенерировать командой:

```
python tools/generate_assets.py
```

Примеры экранов лежат в папке `Screenshots`.

## Проверка без графики

```
python simulate.py              # набор полей, по 5 партий
python simulate.py 15 9 3 20    # поле 15x9, 3 яблока, 20 партий
```
