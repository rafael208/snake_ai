# Snake AI

Змейка на Python + pygame с автопилотом, графическим меню и
соревнованием в двух окнах.

## Запуск

```bash
python -m pip install -r requirements.txt
python main.py
```

Проверка автопилота без графики:

```bash
python simulate.py
```

## Управление

- **SMART** — играет автопилот;
- **MANUAL** — стрелки / WASD;
- **СОРЕВНОВАНИЕ** — два окна: ИИ против игрока;
- скорость игры выбирается в меню: 4–20 FPS;
- **Space** — пауза, **R** — заново, **Esc** — меню.
