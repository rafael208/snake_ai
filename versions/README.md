# Версии алгоритма

- [`safe_cycle_ai`](safe_cycle_ai) — историческая версия, в которой
  автопилот всегда использует только безопасный гарантированный обход
  кольца (`CYCLE`), без быстрого жадного сбора яблок. В папке есть
  отдельные тесты и метрики: `benchmark.py`, `RESULTS.md`,
  `results.json`.
