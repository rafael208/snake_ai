# Метрики historical-версии: только безопасный цикл

В этой версии `SnakeAI.fast_enabled = False`: на каждом ходу
используется только гарантированный обход кольца (CYCLE) и,
если нужно, восстановление (RECOVERY). Жадного FAST-режима нет.

Игра считалась пройденной, когда тело заполняло всё поле.
Время в игре рассчитано для `FPS = 8` по формуле:

```
минуты = ходы / 8 / 60
```

CPU-время — это время headless-симуляции без графики, не время
реальной игры. Для 30×30 с одним яблоком партия очень длинная,
поэтому запускался один seed.

Кратко: **51 партия из 51 выиграна**. При 10 яблоках партия занимает
около 0,1 минуты на 5×5, 0,6 минуты на 10×10, 8,9 минуты на 20×20 и
44,9 минуты на 30×30. При одном яблоке время резко растёт: 79,7 минуты
на 20×20 и 407,9 минуты (около 6,8 часа) на 30×30 — чистому кольцу
приходится очень долго ждать появления следующего яблока.
