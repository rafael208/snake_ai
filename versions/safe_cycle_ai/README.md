# Historical version: guaranteed CYCLE only

Это отдельная папка с исторической версией алгоритма змейки.

В текущей версии проекта на старте включается быстрый безопасный сбор
яблок (`FAST`), а при росте опасности происходит переход на кольцо.
Здесь этот слой отключён: используется **только гарантированный обход
кольца** (`CYCLE`) и восстановление (`RECOVERY`), то есть поведение
автопилота примерно до появления жадного старта.

## Что изменено относительно текущей версии

- `SnakeAI.fast_enabled = False`;
- из `choose_move` удалён вызов `_fast_move`;
- в `Competition` быстрый режим также не включается;
- остальная логика, UI и ассеты соответствуют текущему проекту.

FAST-код остался в `ai.py` как неиспользуемый исторический код, но
автопилот его не вызывает. Поэтому все партии ниже — чистый `CYCLE`.

## Запуск

Из этой папки:

```bash
python main.py
```

Проверка без графики:

```bash
python simulate.py
```

## Тесты и метрики

```bash
python benchmark.py
```

Скрипт запускает партии на полях 5×5, 6×6, 7×7, 10×10, 15×15, 20×20 и
30×30 с 1, 3 и 10 яблоками, считает ходы, CPU-время headless-симуляции
и переводит ходы в игровое время при `FPS = 8`:

```text
минуты = ходы / 8 / 60
```

Результаты записываются в [`RESULTS.md`](RESULTS.md), подробности по
seed — в [`results.json`](results.json).

Важно: это реконструкция по поведению, а не git-снимок. Git-репозитория
в проекте не было, поэтому версия собрана из текущего кода отключением
FAST-режима.
